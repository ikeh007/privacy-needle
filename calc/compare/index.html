    How to use this comparison

    Enter the number of reference virtual machines, monthly running hours, database capacity, at-rest storage, outbound transfers and serverless invocations. Each provider is modeled with a documented or illustrative per-unit reference, adjusted by your entries. Open the pricing editor before making a procurement decision.

    Comparison limits

    Compute reference shapes are intentionally different. AWS T3 instances have CPU credit characteristics; Azure B-series machines are burstable; the Google E2 medium reference is shared-core; and Oracle E4.Flex uses OCPUs. These reference profiles should not be interpreted as guaranteed performance equivalence. The calculator is designed for early budgeting and scenario sensitivity, not production quotations.

    Where to go next

    Review the pricing source register, read the cloud comparison guide or focus on one provider: AWS, Azure, Google Cloud or Oracle.

    Frequently asked questions

    Are these official cloud provider quotations?

    No. Privacy Needle Calc generates browser-side planning estimates using editable reference rates. Official regional SKUs, service tiers, free allowances, reservations, taxes and contract discounts may differ.

    Does the calculator include all cloud charges?

    No. It models selected compute, database, storage, network, request, support and contingency line items. CPU time for functions, managed service features, logs, support entitlements, security products and taxes may be additional.

    Can I save or share the estimate?

    Yes. You can export CSV and JSON, print to PDF, create a shareable input URL or save a scenario to this browser.
